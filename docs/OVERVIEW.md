# Ontology overview

This package defines a machine-checkable encoding for time-travel and interacting-multiverse stories.

## Three layers

1. **Rule sets** (`src/catalog/rules.ts`) — named fictional physics / law variants (fixed timeline, mutable ripple, branching, bootstrap, loops, worldlines, entropy inversion, tangent universes, multiverse contact, prune bureaucracy, death checkpoints, perception nonlinearity, …).
2. **World topology** (`src/catalog/topologies.ts`) — how **Timeline**, **Branch**, and **ParallelWorld** relate. These three are **distinct primitives**, not synonyms.
3. **Narrative encoding** (`StoryEncoding`) — agents, events, edges, interventions, and outcomes under chosen laws + topology.

## Source of truth

- Zod schemas in `src/schema/` are authoritative.
- `schema/ontology.schema.json` is generated by the build script for non-TS consumers.
- Files under `instances/` must pass the validate script.

## Non-goals

- No visual/diagram engine in this repo.
- No literary quality scoring.
- No ad-hoc per-story fields outside the schema (strict objects on root and core types).

## Consumers

- Humans / agents formalising plotlines for comparison across a corpus.
- A separate visual engine that reads worlds, events, and edges (see ENCODING-GUIDE.md).

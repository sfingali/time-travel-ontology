# time-travel-ontology

Machine-checkable TypeScript + Zod ontology for time-travel and multiverse encodings.

## Scripts

- build / validate / test / export-schema / import

import emits draft stubs to instances/generated/ from time-travel-archive; never overwrites hand-crafted instances/*.json.

## Docs

- docs/OVERVIEW.md RULES.md TOPOLOGY.md NARRATIVE.md ENCODING-GUIDE.md COMPATIBILITY.md

primaryRuleSetId is required; mixinRuleSetIds optional. See COMPATIBILITY.md.

# time-travel-ontology

Machine-checkable ontology for **time-travel and interacting multiverse** stories.

## Purpose
Encode any plotline as:
1. **Rule set** — fictional physics / law variants (fixed timeline, mutable past, branching, bootstrap constraints, paradox handling, …)
2. **World topology** — how timelines, branches, and parallel worlds relate (distinct primitives)
3. **Narrative graph** — events, interventions, causal links, outcomes under those laws

Intended consumers: human/agent formalisation workflows; a **separate** visual engine (out of scope here).

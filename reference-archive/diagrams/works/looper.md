# Looper (2012) — diagram archaeology

**Type focus:** causality + branching timeline  
**Model:** Hybrid — some futures rewrite when past changes (Rainmaker), but closed-loop aesthetics remain (Old Joe’s memories).

## What the diagrams show

### Nodes
- Young Joe / Old Joe / Rainmaker child / Sara / Abe / Gat Men
- Kansas fields loop pads; Shanghai future; diner confrontation

### Loops
- “Closing the loop” = killing one’s future self sent back.
- Talley **straw diagram** (Slate): physical-metaphor causality straws for Joe’s path vs Rainmaker timeline.

### Branches
- Iliinsky Complex Diagrams / Wired chart: maps malleable vs immutable cues; asks whether Joe’s final choice truly alters the probable future.
- Diagrams show **Old Joe’s originating future** coexisting conceptually with the rewritten present.

## Key sources
Slate/Talley straws; complexdiagrams.com; Gizmodo; Time Out; Il Sorpasso.

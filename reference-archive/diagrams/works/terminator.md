# Terminator franchise — diagram archaeology

**Type focus:** causality (bootstrap) · multiverse map (franchise-wide)  
**Model:** Judgment Day attractor; Kyle Reese fatherhood bootstrap; later films add branching / erased futures.

## What the diagrams show

### Nodes
- Sarah / John Connor, Kyle Reese, Terminators (T-800, T-1000, …), Skynet
- 1984 / 1991 / 1995 / future war eras

### Loops
- T1: Reese sent back → fathers John → leads resistance → sends Reese (bootstrap).
- Tech bootstrap variants (chip / Skynet origin) in later entries.

### Branches
- Talley **straw franchise diagram** attempts to reconcile T1–T5 (+ SCC) as overlapping straws — visual metaphor for contradictory sequels.
- T2’s prevented Judgment Day vs later films’ restored JD often drawn as **reborn branches**.

# Diagram Classification — real chart vs. still/screenshot
_Updated 2026-09-07 (fourth pass, after restructuring `assets/` to one folder per work)._
For each image under `assets/`, marks whether it is a genuine timeline/chart/graph
diagram or a film still / web-page screenshot. Base = visual review of contact
sheets + per-image vision reads. Every diagram shown here was verified to be a
real chart (not a poster). Stills and article screenshots were **removed**, not
kept.

Legend: **chart** = genuine timeline/causality/family-tree/multiverse diagram.
**still** = film still / poster. **shot** = web-page screenshot (no underlying
diagram). **sliver** = extreme-aspect but real chart.

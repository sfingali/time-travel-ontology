# Time Travel Reference Archive

Curated reference corpus for the [time-travel-ontology](https://github.com/sfingali/time-travel-ontology) project: film/TV/novel notes, sources, and diagram assets used while building the ontology.

## Layout

- `films/`, `tv/`, `novels/` — work notes and analyses
- `diagrams/` — diagram indexes plus `assets/` (PNG/SVG/JPG variants and harvests)
- `sources/`, `candidates/`, `parallel-universe/`, `logs/` — supporting research material
- `index.md` — top-level index

This tree is a snapshot of the local `time-travel-archive` burn corpus, published under `reference-archive/` for versioned reference.

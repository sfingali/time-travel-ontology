# See You Yesterday (2019)

## Short blurb
Brooklyn science prodigies build time machines to save a brother killed by police—and learn TT’s costs.

## Detailed plot summary
Netflix film produced by Spike Lee. Claudette and Sebastian invent portable time travel to undo CJ’s shooting. Each attempt creates new collateral damage. Explicit social-justice framing of time travel’s inability to cheaply erase systemic violence.

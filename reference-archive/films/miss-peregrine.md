# Miss Peregrine's Home for Peculiar Children (2016)

## Short blurb
Jake finds a WWII orphanage preserved in a repeating September 3, 1943 loop protected by Miss Peregrine.

## Detailed plot summary
Adaptation of Ransom Riggs. Peculiars live inside a day-loop that resets before a deadly bombing; Hollowgasts/wights hunt them. Jake’s peculiarity (seeing hollows) makes him central. Loop is a defensive pocket rather than character-growth Groundhog Day.

## Timeline/structure notes
- Time loop as sanctuary mechanics.
- Burton visual style; lore expands in sequels/books.

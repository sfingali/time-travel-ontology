# Source Code (2011)

## Short blurb
Captain Colter Stevens repeatedly relives the last eight minutes of a dead teacher’s life on a bombed Chicago train to find the bomber—and discovers Source Code may create lasting branching realities.

## Detailed plot summary (spoilers)
Stevens wakes on a train as Sean Fentress, guided by Goodwin (Farmiga) in a capsule. He must identify the bomber before a larger dirty-bomb attack. After many failures he finds the bomber, relays info, saves the city in “real” timeline—then defies shutdown, kisses Christina, and continues in a branch where the train never exploded. Capsule reveal: Stevens’s mutilated body is the hardware; Goodwin euthanizes him in base reality while branch-Stevens texts her. Ending implies Source Code generates persistent alternate worlds, not mere sims.

## Temporal / ontological analysis
- Official brief: “cannot change the past,” only extract info—echo 12 Monkeys.
- Ending reframes as branching/multiverse creation (debate central to explainers).
- Eight-minute constraint as narrative governor.
- Duncan Jones’s second feature after Moon.

# Groundhog Day (1993)

## Short blurb
Narcissistic weatherman Phil Connors relives February 2 in Punxsutawney until kindness and craft replace cynicism—the template that named a paradox genre.

## Detailed plot summary (spoilers)
Phil (Murray), Rita (MacDowell), and Larry cover Groundhog Day. Phil wakes repeatedly to the same radio cue, town rituals, and Ned Ryerson. Stages documented in criticism and Rubin interviews: confusion → hedonism → despair/suicide attempts (each resetting) → skill acquisition (piano, French, ice sculpting, saving lives) → genuine care for Rita and townsfolk → release into February 3.

Mechanism never explained (no machine). Exit condition is moral/spiritual transformation, not puzzle solution—distinguishing it from Happy Death Day / Source Code information loops.

## Temporal structure & analysis
- Closed daily loop; Phil retains memory and learning; world resets.
- Time-span estimates vary wildly in fan calculation (days to thousands of years); filmmakers intentionally vague.
- Genre namesake: “Groundhog Day loop” tag across this archive.
- Influences later Palm Springs, Edge of Tomorrow, Russian Doll, Map of Tiny Perfect Things, etc.

## Production / cuts
Rubin’s original darker drafts differed; Ramis collaboration shaped comic-philosophical tone. No theatrical alternate ending that changes loop logic in standard sources.
